## 📖 Overview

Zashly is a full-stack real-time chat and social networking application focused on delivering fast, secure, and engaging communication experiences.

The platform combines messaging, voice & video calling, social stories, media sharing, and group collaboration into a modern and scalable web application.

---

## ✨ Key Features

- ⚡ Real-time one-to-one messaging
- 👥 Group chats
- 📞 Voice & Video Calling
- 🌟 Moments (Stories)
- ❤️ Story reactions
- 👀 Story viewer tracking
- 🖼️ Image, video & file sharing
- 📊 Interactive polls
- 🎨 Chat personalization
- 🤝 Friend request system
- 👤 User discovery
- 👮 Group admin controls
- 🔔 Live notifications
- 🟢 Online / Offline presence
- 🔒 JWT Authentication
- 🛡️ Privacy & moderation system
- 📱 Responsive design
